# EletricShop - Sistema de Gerenciamento

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Linguagem:** Python 3.13 (Inclui Tkinter)
* **Gerenciador de Pacotes:** pip (Versão 25.3) 
* **Interface Gráfica (GUI):** Tkinter (Tcl/Tk 8.6)
* **Banco de Dados:** MySQL (Versão X.X)
* **Conector:** mysql-connector-python (Versão 9.5.0)

## 🚀 Como Executar o Projeto

1.  **Instale as Dependências:**
    ```bash
    pip install mysql-connector-python
    ```
    (Se você tiver outras bibliotecas, liste-as aqui.)

2.  **Configure o Banco de Dados:**
    * Crie o banco de dados `eletric_shop` no seu servidor MySQL.
    * Execute o script SQL inicial (create table, insert admin).

3.  **Execute o Aplicativo:**
    ```bash
    python main.py
    ```
